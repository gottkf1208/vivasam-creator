  • 샘크리에이티브 연수 = 선생님이 직접 만들어가는 직무연수, 6차시(15차시 미만) 실습형이 기본 단위
  • 과정소개는 학습목표 4개 + 과정 특징 4개, 강의목차는 6차시 제목, 강사 2~3인
  • 평가: 진도율 90% / 시험 0% / 의견등록 100% · 이수 기준 진도율 90%, 60점 이상
  • 기준 과정: '6차시 완성! 캔바로 수업·디자인 한 번에' (30,000원, 연중)

코드에서 고치는 법

내용은 data/*.json, 슬라이드 구성은 build.py, 디자인은 engine.css, 조작(대본·목차·편집·BGM)은 engine.js예요. 고친 뒤 python build.py를 실행하면 dist/에 단일 HTML 세 편이 다시 만들어져요. 브라우저 편집 모드(E)로 글자를 고치면 깃허브 페이지에서는 *.edits.json으로 저장돼요.
